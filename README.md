## 📖 Overview

**Age Calculation** is a simple JavaScript-based web application that calculates a user's age from their date of birth.

The project focuses on practicing JavaScript date manipulation, user input handling, calculations, DOM manipulation, and interactive UI development.

---

## ✨ Features

* 🎂 Calculate age from date of birth
* 📅 Date input
* 🧮 Automatic age calculation
* ⚡ Instant result
* 🚫 Input validation
* 📱 Responsive design
* 🎨 Clean and simple interface
* 💻 No external JavaScript libraries required

---

## 🧠 How It Works

The application follows a simple calculation flow:

```text
User enters date of birth
          ↓
Application reads the input
          ↓
Current date is calculated
          ↓
Birth date is compared
          ↓
Age is calculated
          ↓
Result is displayed
```

---

## 🔢 Age Calculation Logic

The application compares the user's birth date with the current date.

The basic calculation is:

```text
Age = Current Year - Birth Year
```
